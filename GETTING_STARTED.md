## 🚀 Quick Start (3 Steps)

### Step 1: Choose Your Goal

**If you want to LEARN Python:**
1. Start by reading the main [README.md](README.md)
2. Follow the learning path from Practical 1 → 2 → 3 → 4
3. Read each practical's README before looking at code

**If you want to COPY code:**
1. Navigate to the practical folder you need
2. Open the `.py` file
3. Copy the code - it's fully commented and ready to use

**If you need QUICK REFERENCE:**
1. Open [QUICK_REFERENCE.md](QUICK_REFERENCE.md)
2. Find the concept you need (lists, dictionaries, etc.)
3. Copy the syntax example

### Step 2: Set Up Your Environment

**Requirements:**
- Python 3.6 or higher
- Text editor or IDE (VS Code, PyCharm, etc.)
- Terminal/Command Prompt

**Check if Python is installed:**
```bash
python3 --version
```

**If not installed:**
- Windows: Download from [python.org](https://python.org)
- Mac: `brew install python3`
- Linux: `sudo apt-get install python3`

### Step 3: Run Your First Program

```bash
# Navigate to the repository
cd Folders/

# Run Practical 1, Task 1
python3 Practical_1/task1.py
```

You should see:
```
Alex 101 3.8
<class 'str'>
<class 'int'>
<class 'float'>
```

**Congratulations! You're ready to go!** 🎉

## 🎓 Learning Tips

### 1. Read Before Running
Don't just run code. Read the README first to understand what you'll learn.

### 2. Type, Don't Just Copy
Typing code helps you remember. Even if you copy-paste, type it out at least once.

### 3. Experiment
Change values, add features, break things (intentionally) to learn how they work.

### 4. Use Comments
The code is heavily commented. Read every comment to understand WHY, not just WHAT.

### 5. Practice Exercises
Each README has practice exercises. Actually do them - that's where real learning happens.
